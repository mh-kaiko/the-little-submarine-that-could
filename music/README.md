# Music

The tracks are copyrighted, so they are git-ignored and never pushed. Drop
your own copies here:

| File        | Plays                          |
| ----------- | ------------------------------ |
| `level.mp3` | title screen and normal play   |
| `boss.mp3`  | while a boss is on screen      |

Both loop, and the music fades out on game over. Any file missing means
silence for that part, not a crash. The team's picks are in the jam Slack
thread (Bowser's Fury / Bowser's Super Eternal Fury).
